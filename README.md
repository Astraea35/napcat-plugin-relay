# 📨 napcat-plugin-relay

**NapCat 消息中转与引用回复插件（支持好友申请审批与免打扰过滤）**

专为 [NapCat](https://github.com/NapNeko/NapCatQQ) 开发的双向消息中转传话与好友管理插件。支持将机器人收到的私聊与群聊消息自动转发给指定管理员 QQ，管理员只需直接【引用回复】中转消息，即可自动送达原发送者；同时支持好友申请实时推送与一键引用回复审批，内置会话框消息免打扰（DND）智能过滤功能。

---

## ✨ 核心特性

- 📥 **自动双向消息中转**
  - **私聊消息**：陌生人或好友发送给机器人的私聊消息，自动添加发送者前缀并中转给目标管理员 QQ。
  - **群聊消息**：支持转发群聊消息（默认仅转发艾特机器人的群消息，防止刷屏）。
  - **富文本多媒体**：支持文字、图片、表情等各类消息类型的原样中转。
- ↩️ **智能引用回复送达**
  - 管理员在 QQ 私聊中直接【引用回复】机器人发来的中转消息，插件自动解析原发送者并将回复内容转回。
  - 支持回转至私聊好友或原群聊（群聊回复自动 @原发送者）。
  - 支持发送成功回执提示（可配置关闭）。
- 🤝 **好友申请推送与快捷审批**
  - **申请卡片推送**：收到新好友申请时，自动将申请人昵称、QQ、验证消息/附言推送到管理员私聊。
  - **引用回复一键处理**：直接【引用回复】好友申请通知卡片：
    - 回复「同意」或「同意 备注名」即可快速通过申请，并可选直接设置好友备注！
    - 回复「拒绝」即可拒绝该好友申请。
  - **指令审批**：支持直接发送指令 #同意 <QQ号> [备注名] 或 #拒绝 <QQ号>。
  - **自动通过规则**：可选开启全局自动同意，或设置关键词匹配验证消息自动同意。
- 🔕 **消息免打扰（DND）智能过滤**
  - **QQ 客户端自动识别**：自动获取 QQ NT 核心群消息提醒状态（groupMask）。凡在 QQ 客户端中设置了【接收不提醒 (免打扰)】、【屏蔽群消息】或【进群助手】的群聊，消息一律自动跳过，绝不打扰管理员。
  - **手动免打扰名单**：支持在 WebUI 中添加或通过聊天指令快捷添加免打扰 QQ/群号。
- 💬 **管理员快捷指令（私聊发送）**
  - #中转状态 或 #relay：查看插件运行状态、各功能开关与活跃引用映射条数。
  - #免打扰 或 #dnd：查看当前免打扰过滤状态与手动免打扰名单。
  - #添加免打扰 <QQ号或群号>：将指定会话添加至免打扰名单，后续不再转发。
  - #删除免打扰 <QQ号或群号>：将指定会话移出免打扰名单，恢复转发。
  - #同意 <QQ号> [备注名]：通过指定好友申请。
  - #拒绝 <QQ号>：拒绝指定好友申请。
- 💾 **断电与重启持久化**
  - 消息引用映射关系在内存中维护并自动防抖保存至 message_map.json，重启容器引用不失效。
  - 插件配置持久化至 config.json。
- ⚙️ **WebUI 可视化配置**
  - 完美适配 NapCat WebUI 插件管理界面，可视化修改配置即刻生效。

## 📦 安装方法

### 方式一：克隆仓库安装

进入 NapCat 的插件目录（如 
apcat/plugins 或数据卷映射目录）：

`ash
cd /app/napcat/plugins
git clone https://github.com/Astraea35/napcat-plugin-relay.git
`

### 方式二：手动下载

1. 下载本仓库源码解压。
2. 将解压后的文件夹重命名为 
apcat-plugin-relay，放入 NapCat 的 plugins 目录下。
3. 重启 NapCat 即可自动加载。

## ⚙️ 配置说明

插件首次加载后，可直接在 **NapCat WebUI -> 插件管理 -> 消息中转传话** 中进行图形化配置：

| 配置项 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| 	arget_qq | string | "" | **必填**。接收所有中转消息与好友申请的目标管理员 QQ 号 |
| orward_private | boolean | 	rue | 是否转发好友与陌生人的私聊消息 |
| orward_group | boolean | alse | 是否转发群聊消息 |
| orward_group_at_only | boolean | 	rue | 当开启群聊转发时，是否仅转发 @机器人的消息 |
| orward_friend_request | boolean | 	rue | 是否将收到的好友申请推送给管理员，并支持在私聊中一键审批 |
| uto_approve_friend | boolean | alse | 是否自动同意所有好友申请（无需手动审核） |
| uto_approve_keyword | string | "" | 当好友申请验证消息包含该关键字时自动同意（留空不启用） |
| ignore_dnd | boolean | 	rue | 自动识别并跳过 QQ 客户端设置了【免打扰】或【屏蔽】的会话 |
| dnd_list_str | string | "" | 手动免打扰名单，多个 QQ 号或群号用逗号/空格隔开 |
| show_sender_info | boolean | 	rue | 转发消息时是否附加 [来自私聊: 昵称(QQ)] 等信息前缀 |
| send_confirmation | boolean | 	rue | 引用回复成功送达后，是否向管理员发送成功提示回执 |
