# 📨 napcat-plugin-relay

**NapCat 消息双向中转与智能引用回复插件（备注名优先、文件转发、引用原消息、好友审批、免打扰过滤与定时群发月薪喵）**

专为 [NapCat](https://github.com/NapNeko/NapCatQQ) 开发的双向消息中转传话与管理插件。支持将机器人收到的私聊与群聊消息自动转发给指定管理员 QQ，管理员只需直接【引用回复】中转消息，即可自动送达原发送者；同时支持好友备注名优先展示、私聊/群聊文件原生中转、向好友回复时自动引用对方原消息、好友申请实时推送与一键审批、会话消息免打扰（DND）智能过滤，以及**每日固定时间向指定群聊自动发送最新月薪喵打工表情包**。

---

## ✨ 核心特性

- 📥 **自动双向消息中转**
  - **私聊消息**：好友与陌生人发送给机器人的私聊消息，自动中转给管理员 QQ。
  - **群聊消息**：支持转发群聊消息（默认仅转发艾特机器人的群消息，防止刷屏）。
  - **富文本多媒体**：支持文字、图片、表情、语音、长消息等原样中转。
- 🏷️ **好友备注名优先展示（全局适配）**
  - **备注名优先级最高**：默认优先使用您在 QQ 为好友设置的【备注名】（如回执显示 `张三 (12345678)`），不再只显示好友自行设置的原始 QQ 昵称。
  - **原昵称追加开关**：支持在 WebUI 或通过指令随时切换是否在备注名后附带用户原昵称（开启后格式为 `张三 (小张) (12345678)`；关闭则纯净显示 `张三 (12345678)`）。
  - **全场景统一**：中转消息前缀、回复成功回执、好友申请通知、好友通过卡片等全局统一生效。
  - **自动与手动缓存**：启动自动预加载好友备注，支持通过 `#刷新好友` 随时同步最新修改的 QQ 好友备注。
- 📁 **私聊与群聊文件自动转发**
  - **原生文件卡片直推**：对方发送文件时，机器人自动通过 QQ NT 原生单条转发（`forward_friend_single_msg`）将文件卡片推达管理员，管理员可在 QQ 聊天框中直接点击下载。
  - **文件详情提示卡片**：同步生成文件信息看板，展示发送人、文件名、格式化文件大小及下载直链（若有）。
  - **回转交互闭环**：管理员直接【引用回复】该文件提示卡片，即可将回复消息转回发文件的原好友或原群聊。
- 💬 **回复对方时自动【引用回复】原消息**
  - **智能上下文引用**：管理员回复中转消息时，机器人向原好友或原群聊发送消息时，会自动【引用回复】对方最初发送的那条原始消息，让对方一目了然知道在回复哪句话。
  - **随时开关控制**：WebUI 提供「回复对方时使用引用回复」开关，私聊中亦可使用 `#开启引用回复` / `#关闭引用回复` 随时切换。
- 🤝 **好友申请推送与快捷审批**
  - **全链路智能拦截**：无论是 OneBot 标准请求事件，还是 QQ NT 私聊下发的「请求添加你为好友」系统消息，插件均会自动拦截，格式化为包含申请人昵称、QQ 号、验证消息及详细操作指引的交互卡片。
  - **引用回复一键处理**：直接【引用回复】好友申请通知卡片：
    - 回复「同意」、「/同意」或「同意 备注名」即可快速通过申请，并可选直接设置好友备注！
    - 回复「拒绝」或「/拒绝」即可拒绝该好友申请。
  - **智能容错兜底**：若引用了申请人发送的普通私聊消息并输入 `/同意`，插件会自动识别并优先执行审批通过或备注修改，绝不会将 `/同意` 当作普通私聊原文转发给对方。
  - **指令审批**：支持直接发送指令 `#同意 <QQ号> [备注名]` 或 `#拒绝 <QQ号>`。
  - **自动通过规则**：可选开启全局自动同意，或设置关键词匹配验证消息自动同意。
- 🔕 **消息免打扰（DND）智能过滤**
  - **QQ 客户端自动识别**：自动获取 QQ NT 核心会话提醒状态（groupMask/isBlocked）。凡在 QQ 客户端中设置了【接收不提醒 (免打扰)】、【屏蔽群消息】或【进群助手】的群聊与屏蔽私聊，消息一律自动跳过，绝不打扰管理员。
  - **手动免打扰名单**：支持在 WebUI 中添加或通过聊天指令快捷添加免打扰 QQ/群号。
- ⏰ **定时群发月薪喵表情包（支持时间随机浮动）**
  - **内置持久化表情**：内置最新打工「月薪喵」抹泪动图资源（`assets/monthly_salary_cat.gif`），不依赖网络下载或 QQ 临时缓存。
  - **群聊与时间自定义**：目标群聊（`schedule_groups`）和每日触发时间点（`schedule_times`）完全由用户自由配置，支持多群聊、多时间点。
  - **前后随机时间浮动**：支持设置随机浮动范围（`schedule_random_minutes`，例如设为 15 分钟），系统每天自动在 `[设定时间 - 15分, 设定时间 + 15分]` 之间生成完全不固定的自然随机执行时间，避免机械化准点触发。
  - **自定义扩展**：支持附加说明文字，或配置替换为自定义图片 URL / 本地路径。
- 🛠️ **管理员快捷指令（私聊向机器人发送）**
  - `#中转状态` 或 `#relay`：查看插件运行状态、免打扰设置、定时群发状态、今日实际随机发送计划与映射条数。
  - `#刷新好友` / `#更新好友`：强制重新拉取并更新所有好友的最新备注名缓存。
  - `#开启原名` / `#关闭原名`：切换是否在备注名后面附带显示用户真实 QQ 昵称。
  - `#开启引用回复` / `#关闭引用回复`：切换机器人回复对方时是否引用对方的原消息。
  - `#开启文件转发` / `#关闭文件转发`：切换文件转发功能开关。
  - `#测试月薪喵 [群号]` / `#月薪喵`：立即向指定群或所有已配置群发送月薪喵表情包进行测试（未配置群聊时私聊发送预览）。
  - `#设置群聊 <群号1, 群号2...>`：快捷设置定时发送的目标群号列表。
  - `#设置时间 <09:00, 12:00, 18:00>`：快捷设置每日定时发送的时间点。
  - `#设置随机 <分钟数>`：设置定时发送在设定时间点前后随机浮动的分钟数（如 `#设置随机 15` 表示前后 ±15 分钟随机发送，`#设置随机 0` 为准点）。
  - `#开启月薪喵` / `#关闭月薪喵`：快速启用或暂停定时群发。
  - `#免打扰` 或 `#dnd`：查看当前免打扰过滤状态与手动免打扰名单。
  - `#添加免打扰 <QQ号或群号>`：将指定会话添加至免打扰名单，后续不再转发。
  - `#删除免打扰 <QQ号或群号>`：将指定会话移出免打扰名单，恢复转发。
  - `#同意 <QQ号> [备注名]`：通过指定好友申请。
  - `#拒绝 <QQ号>`：拒绝指定好友申请。
- 💾 **断电与重启持久化**
  - 消息引用映射关系在内存中维护并自动防抖保存至 `message_map.json`，重启容器引用不失效。
  - 插件配置持久化至 `config.json`。
- ⚙️ **WebUI 可视化配置**
  - 完美适配 NapCat WebUI 插件管理界面，可视化修改配置即刻生效。

## 📦 安装方法

### 方式一：克隆仓库安装

进入 NapCat 的插件目录（如 `/app/napcat/plugins` 或宿主机数据卷挂载目录）：

```bash
cd /app/napcat/plugins
git clone https://github.com/Astraea35/napcat-plugin-relay.git
```

### 方式二：手动下载

1. 下载本仓库源码解压。
2. 将解压后的文件夹重命名为 `napcat-plugin-relay`，放入 NapCat 的 `plugins` 目录下。
3. 重启 NapCat 即可自动加载。

## ⚙️ 配置说明

插件首次加载后，可直接在 **NapCat WebUI -> 插件管理 -> 消息中转传话** 中进行图形化配置：

| 配置项 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `target_qq` | string | `""` | **必填**。接收所有中转消息与好友申请的目标管理员 QQ 号 |
| `forward_private` | boolean | `true` | 是否转发好友与陌生人的私聊消息 |
| `forward_group` | boolean | `false` | 是否转发群聊消息 |
| `forward_group_at_only` | boolean | `true` | 当开启群聊转发时，是否仅转发 @机器人的消息 |
| `forward_file` | boolean | `true` | 是否自动转发私聊与群聊收到的文件 |
| `enable_quote_reply` | boolean | `true` | 管理员回复时，机器人向原好友发送消息是否【引用回复】对方的原消息 |
| `show_original_nickname` | boolean | `false` | 开启后若好友有备注名，显示为「备注名 (原昵称)」；关闭则仅显示「备注名」 |
| `forward_friend_request` | boolean | `true` | 是否将收到的好友申请推送给管理员，并支持在私聊中一键审批 |
| `auto_approve_friend` | boolean | `false` | 是否自动同意所有好友申请（无需手动审核） |
| `auto_approve_keyword` | string | `""` | 当好友申请验证消息包含该关键字时自动同意（留空不启用） |
| `ignore_dnd` | boolean | `true` | 自动识别并跳过 QQ 客户端设置了【免打扰】或【屏蔽】的会话 |
| `dnd_list_str` | string | `""` | 手动免打扰名单，多个 QQ 号或群号用逗号/空格隔开 |
| `show_sender_info` | boolean | `true` | 转发消息时是否附加 [来自私聊: 备注名(QQ)] 等信息前缀 |
| `send_confirmation` | boolean | `true` | 引用回复成功送达后，是否向管理员发送成功提示回执 |
| `enable_schedule` | boolean | `true` | 是否开启定时向群聊发送月薪喵表情包 |
| `schedule_groups` | string | `""` | 定时发送目标群号列表，多个群号用逗号、空格或换行分隔（如：`123456, 7891011`） |
| `schedule_times` | string | `"09:00, 12:00, 18:00"` | 每日定时发送时间点列表（24小时制 HH:mm，逗号分隔） |
| `schedule_random_minutes` | number | `0` | 定时发送前后随机浮动范围（分钟）。如设为 15，则在目标时间点前后 15 分钟内随机触发；设为 0 则准点发送 |
| `schedule_text` | string | `""` | 发送表情包时随图附带的文字消息（留空则纯发图） |
| `schedule_custom_image` | string | `""` | 自定义表情图片路径/URL（留空则默认使用内置最新月薪喵动图） |
